Validation Methodology

Each stock is evaluated using historical daily data. Technical indicators are calculated using only information available at each historical test date. The prediction is compared with the actual price direction after five trading days.

A future return above +1% is classified as BUY, a return below -1% as SELL, and movements between -1% and +1% as NEUTRAL.

Accuracy, precision, recall and F1 score are calculated only for actionable BUY and SELL predictions.
